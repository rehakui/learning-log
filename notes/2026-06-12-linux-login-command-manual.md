## コマンド

### コマンド書式

コマンドには決まった書式がある。

### オンラインマニュアル

Linuxにはコマンドの使い方を調べるためのオンラインマニュアルがある。

* **man** → マニュアルを表示するコマンド
* **pager（ページャ）** → 長いテキストをページ単位で閲覧するソフト
* **less** → 代表的なページャ

### less の主な操作

* Space：次のページ
* b：前のページ
* /文字列：検索
* q：終了

## manコマンド

今の理解

* Linux大百科（辞書）のようなもの
* 分からないコマンドを調べるために使う

例

```bash
man ls
man pwd
man cp
```

### セクション番号

* 1：一般コマンド
* 5：設定ファイル
* 8：管理者向けコマンド

※まだ完全には理解できていないが、「辞書の章番号」のようなイメージ。

例

```bash
man passwd
man 5 passwd
```

## --help

コマンドの簡易的なヘルプを表示する。

例

```bash
ls --help
cp --help
```

分からないときは

1. `--help`
2. `man`

の順で調べる習慣をつける。
